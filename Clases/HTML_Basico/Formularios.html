Formularios

Teoría

Los formularios se llaman con la etiqueta de bloque 'form', y así como lo etiqueta 'ol' o 'ul', estas necesitan algo adentro para hacer un formulario y eso es la etiqueta 'input', es la manera que tengo para que el usuario pueda ingresear información y que la reciba un servidor, existen varios tipos de 'input' que se definen con el atributo 'type' adentro de la etiqueta.

Existen también 3 atributos muy importantes para los input, y estos son:

  • 'required'

    • Hace que el usuarion no pueda enviar el formulario sin completar ese input correctamente, además le agrega un atributo title predeterminado que dice 'Completa este campo'.

  • 'name'

    • Es el atributo que nos ayuda a identificar nuestro input; cuando el campo del input se completa y el formulario se envía, podemos clasificar la respuesta con este atributo

  • 'placeholder'

    • Hace que lo que escribamos dentro, esté ahi hasta que el usuario escriba algo, sirve como introducción, por ejemplo, en un input 'text' puedo poner en el placeholder: coloca tu nombre
