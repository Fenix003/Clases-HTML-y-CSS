Fuentes Externas

Teoría

Las fuentes externas, son aquellas que no se encuentran disponibles en Visual Studio Code. Se tienen que importar desde Google fonts, para eso se tiene que crear un nuevo archivo css exclusivo para las fuentes, y se agrega '@font-face', en 'font family' le ponemos un nombre a la tipografía, en 'src:url = () format ()', descargamos el documento con las fuentes y ponemos la ruta de la tipografía que queremos configurar, más el formato que es 'truetype', y por ultimo configuramos el 'font-weight' y el 'font-style' con el que la vamos a llamar en nuestro archivo de stilos.
