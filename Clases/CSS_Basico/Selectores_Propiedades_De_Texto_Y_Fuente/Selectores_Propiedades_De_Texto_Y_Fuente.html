Selectores, Propiedades de Texto y Fuente

  • Link

    Para que un archivo css se ancle a nuestro archivo html, en el 'head' tenemos que anclar la ruta del archivo css con la etiqueta 'link', antes de el 'href' que es dónde se pone la ruta, está el atributo 'rel' que es el que le indica al archivo html, que archivo esta ingresando, en este caso, cómo es un archivo css, es de tipo stylesheet.

  • Selectores

    • Clases

      Teoría

      Para cada elemento del html que querramos trabajar o modificar en css, tenemos que ponerle una clase, con el atributo 'class', para que en el archivo css podamos identificarlo, para cambierle lo que querramos cambiar.

    • Id

      Teoría

      Las clases se suelen usar para varios elementos que quiero que cumplan con esas características específicas, pero cuando quiero que un solo elemento cumpla una característica en especial, le pingo un 'id' con el atributo 'id', y en el archivo css, lo llamo poniendo un signo numeral (#) y luego el nombre del id.

      Ejemplo

      Top 5 Mejores Juegos

      1. Minecraft
      2. Pokemon
      3. Rocket League
      4. Mario Kart
      5. Overwach

  • Propiedsdes de Texto y Fuente

    Teoría

    En css existen propiedades que solamente cambian el estilo del texto, como lo son, 'font-color' para el color de la letra, 'font-family' para la tipografía, 'font-size' para el tamaño de la letra, 'font-weight' para el grosor de la letra y 'font-style' par poner la letra inclinada, 'text-align' para alinear un texto, centrarlo, justificarlo, 'text-decoration' para subrrayarlo, por arriba, abajo o al medio, 'line-heihgt' para poner un interlineado de algun valor en específico, 'letter-spacing' para definir un espacio entre las letras, 'text-transform' para poner todo el texto en matuscula, minuscula etc
