unidades de medida

teoría

unidades absolutas

Las unidades absolutas son aquellas que no cambian en el entorno virtual, ni dependen de algo en específico

  • píxeles (px)

    Es una unidad de medida que representa un cuadro muy, muy pequeño en una pantalla

  • puntos (pt) y picas (pc)

    Es una medida difícil de encontrar pero se utiliza normalmente cuando se quiere imprimir algo

  • milímetros (mm), centímetros (cm) y pulgadas (in)

    Son unidades que al igual que los Puntos y las Picas son medidas que son pensadas para tener un significado en la impresión en el mundo real

unidades relativas

Las unidades relativas son aquellas que dependen de otra medida, en general, depende de la caja o del elemento que la contiene, también puede ser del valor que le asigna el navegador a algunos valores

  • porcentaje (%)

    Cuando le asignamos a alguna medida un valor en porcentaje, este porcentaje se va a calcular con respecto al valor de la caja o del elemento que lo contiene, es recomendable utilizar porcentajes solo en tamaños de cajas, como width y height

  • em

    Es una unidad de medida que se adapta a los tamaños del elemento padre, o el elemento que lo contiene, esta unidad es muy útil ya que se puede utilizar a la perfección para cualquier medida; si el elemento padre tiene un 'font-size' de 16px, y el sub-elemento tiene un 'font-size' de 1em, tiene 16px, si tiene 2em, tiene 32 y así sucesivamente

  • rem

    Es una unidad que se parece en cierta medida a los 'em', sin embargo, esta unidad no depende del elemento padre, sino del elelemto raiz, que en este caso es el mismo html
