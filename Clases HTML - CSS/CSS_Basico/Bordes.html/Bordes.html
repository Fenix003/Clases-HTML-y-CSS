Bordes

Teoría

La propiedad 'border' nos permite modificar tres aspectos fundamentales de los bordes, como lo son:

  • 'border-width'

    Esta propiedad nos permite cambiar el tamaño del borde, lo podemos medir en píxeles. Es la propiedad que adopta el primer valor en 'border: width'

  • 'border-style'

    Esta propiedad nos permite modificar el estilo del borde: 'solid' para que el borde sea una linea continua, 'dashed' para que el borde sea una línea punteada, 'dashed' para que el borde sea una línea de puntos, 'double' para que el borde sea dos lineas continuas, 'groove' para que el borde tenga un estilo 3D hundido, 'ridge' para que el borde tenga un estilo 3D elevado, 'inset' para que el borde parezca hundido, 'outset' para que el borde parezca elevado y 'none' para que no haya borde.

    Es la propiedad que adopta el segundo valor en 'border: width style'

  • 'border-color'

    Esta propiedad nos permite cambiar el color del borde, normalmente se trabaja en formato hexadecimal. Es la propiedad que adopta el tercer valor en 'border: width style color'

Sin embargo existe otra propiedad que nos permite cambiar otro aspecto puntual de los bordes y que no está dentro de la etiqueta 'Border' y es el Border-radius, el cual permite redondear el borde tanto cómo nosotros queramos, este generalmente se mide en pixeles. De igual manera se pueden dividir los bordes por las caras de la caja, cuando ponemos la propiedad 'Border-radius', las medidas que pongamos se adaptarán a los lados en el sentido horario, y si sólo hay 2 valores, uno lo adoptarán los bordes de arriba y de abajo y el otro, los bordes de la izquierda y la derecha
