Imágenes

Para poner una imagen se utiliza el atributo 'img', esta etiqueta es de las pocas que no se cierra. Y cómo la etiqueta 'a', dentro debe ir el atributo que localice la imagen, que en este caso es 'src', si por alguna razón pusimos la ruta mal, o no se encuentra la imagen, el atributo 'alt' nos ofrece poner un texto que explique la imágen, este solo aparce cuando no se puede proyectar la imagen.
