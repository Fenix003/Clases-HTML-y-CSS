Los parrafos siempre tienen que tener un sentido, cuando cambiamos de parrafo es recompnsable añadir otra etiqueta de parrafo.

Los encabezados son importantes para la estructura de la página, ya que ayudan a organizar el contenido y facilitan la lectura. Es recomendable utilizar los encabezados de manera jerárquica, comenzando con h1 para el título principal, cabe recalcar que es te solo se debe utilizar 1 vez por página web, el resto como el h2 se pueden utilizar cuantas veces sea necesario y descendiendo hasta h6 para los subtítulos más específicos.
